# Pre-merge audit — 11 September 2026

Scope: printable-drill deduplication, language switching, expanded notes, and responsive layouts on the nine shared-shell site pages.

## Findings and fixes

- Hardened the translation cache against malformed saved JSON values and invalid entries. Cache keys cannot resolve through an object's prototype.
- Used literal replacement callbacks so translation text containing JavaScript replacement tokens is displayed literally.
- Added regression checks for malformed caches and rapid language switching back to English while requests are pending.
- Confirmed that the duplicate printable URLs redirect to the interactive drill and are regenerated as redirects, not duplicate question sets.

## Verification results

- `python3 tools/build_site.py`: passed all English source-content and answer-key checks (140 MCQs, 560 options, 151 Q&As, 10 starter answers, 14 book flags, Learn/Write/Revise/Reference text).
- Rebuilding again produced identical HTML hashes.
- `node --check` passed for both JavaScript files; `git diff --check` passed.
- Chromium regression suite: passed 135 combinations of nine pages, three language modes, and widths 320/375/768/1024/1440.
- Browser interactions: navigation/Escape, quiz selection and reveal persistence, question-bank reveal state, search no-results, checklist persistence, language preference, cached switching, failure fallback, malformed storage, rapid switching, and legacy redirects passed.
- Static link audit: all 278 internal links/asset references exist, fragment targets resolve, and IDs are unique across each of the nine site pages.

## Known limitation, not certified by this audit

Translation network responses in the browser regression suite are mocked. The live Google translation endpoint was blocked in this sandbox; successful end-to-end translation with the live provider and translation accuracy are **not verified**. The UI and README disclose the external-service dependency, first-use internet requirement, automatic/Roman-Hindi nature, English fallback, and retry behaviour. English grammar examples should be checked against their originals. These are not human-reviewed or official CBSE translations.

Archived numbered source HTML files are English reference inputs, not shared-shell pages. The responsive/language matrix covers the nine generated website pages.
