1. MethodsOral = fast, no record • Written = proof, slow • Non-verbal = simplest (body + tone/paralanguage) • Visual = crosses languages, best ads • Choice = urgency + distance + audience + record?
2. FeedbackCycle: S→E→M→C→D→R→F • Feedback = receiver's reply back • BEST = Constructive (error + solution) • Matters: confirms + corrects + completes + improves + trust
