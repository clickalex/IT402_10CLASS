⚡ Whole unit in 60 seconds:
  • 3 methods: Verbal (oral + written) • Non-verbal (body + tone) • Visual (charts/signs)
  • Cycle (7): Sender → Encoding → Message → Channel → Decoding → Receiver → Feedback
  • Feedback: receiver's reply back; BEST = Constructive (error + solution)
  • 7 barriers: Physical • Linguistic • Cultural • Emotional • Perceptual • Organisational • Interpersonal
  • 7 Cs: Clear • Concise • Concrete • Correct • Coherent • Complete • Courteous
  • Writing: Topic → Supporting → Concluding • 9 parts of speech (5 basic + 4 supporting) • Articles (a/an/the) + Phrases

Topic 2 — Feedback in Communication Cycle

Cycle stepWho / What
Sender → EncodingSender converts thought → words/gestures
Message → ChannelThe content + medium (speech, email, poster)
Decoding → ReceiverReceiver interprets the message
FeedbackReceiver's reply BACK — completes the loop
Feedback typeOne-line meaning
PositivePraise — "Great presentation!"
NegativePoints error — "Slide 3 is wrong."
Constructive ⭐Error + solution — "…recheck figures, bigger font."
DescriptiveFacts only — "You spoke 12 min, 10 slides."
SpecificExact point — "Your intro was clear."
Immediate / DelayedNod in class / result after a month
Why feedback matters (6)Good feedback is…
1. Confirms understanding • 2. Corrects errors early • 3. Completes cycle • 4. Improves performance • 5. Builds trust • 6. Helps sender improveSpecific • Timely • Factual • Constructive • Polite • About WORK, not person

Topic 3 — Overcoming Barriers

BarrierExampleFix
PhysicalNoise, bad networkQuiet room, working mic
LinguisticFrench manual, jargonSimple words + visuals
Cultural👍 rude abroadLearn customs, respect festivals
EmotionalAnger blocks listeningStay calm, right time
PerceptualJudging before listeningOpen mind, ask first
OrganisationalCan't reach bossOpen-door, suggestion box
InterpersonalDistrust, interruptionsPolite, don't interrupt
8 golden fixes (any question, use these): ① Simple language ② Active listening (eye contact, "So you mean…?") ③ Right medium ④ Remove disturbances ⑤ Give/ask feedback ⑥ Use visuals ⑦ Control emotions ⑧ Repeat/summarise key points.

Topic 4 — Principles: The 7 Cs

CMeansExample

ConcreteFacts + figures"Sales rose 20%"
CorrectRight grammar/factsCheck dates, names, numbers
CoherentLogical orderFirst → Next → Finally
CompleteWhat + when + where + whomInvite with all details
CourteousPolite"Please / thank you / sorry"
🧠 Trick: "Can Cows Chew Cold Corn Cob Candy?" • Bonus principles: Attention • Consistency (words = actions) • Timeliness • Proper channel.

Topic 5 — Basic Writing Skills

RuleLearn it
SentenceSubject + Predicate • CAPITAL start • ./ ? / ! end
4 typesDeclarative ("I study IT.") • Interrogative ("Where?") • Imperative ("Open page 10.") • Exclamatory ("What a goal!")
9 parts of speechBasic: Noun • Pronoun • Verb • Adjective • Adverb + Supporting: Article (a/an/the) • Preposition • Conjunction • Interjection (Wow!/Oh!)
Paragraph① Topic sentence ② 3–4 supporting ③ Concluding line • ONE idea each
Articles + PhraseA (consonant sound) • An (vowel sound) • The (unique/specific) • Phrase = words with NO complete meaning ("in the morning")
PunctuationCapitals: start/names/places/days/"I" • . , ? ! ' :
Do / Don't✅ Plan • short lines • check spelling ❌ Slang • first-draft sending • mixed ideas
🎯 Exam alert: "French manual" = Linguistic • "Any two Cs" = classic 2-marker • Topic sentence + interjection = favourite 1-markers.
